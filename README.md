# Onboarding Platform

AI-generated, personalized (2-month) onboarding plans, built on the Veridian org data.

## Structure

- `docs/PROJECT-README.md` — project seed / decisions from the discovery phase
- `docs/onboarding-framework.md` — the onboarding methodology (17 sections, 6 parts) that agents will build plans from
- `data/Veridian_Master_Data_Pack_v1.xlsx` — source of truth for org data (Employees, Departments, Teams, Offices, Products, Systems, Training Catalog, Policies, Glossary, FAQ, Career Levels, Roles)
- `db/schema.sql` — SQLite schema mirroring the workbook sheets
- `scripts/import-veridian.js` — reads the xlsx and rebuilds `db/veridian.sqlite` from scratch
- `db/veridian.sqlite` — generated (gitignored); run the import script to create it
- `lib/dates.js`, `lib/interfaces.js`, `lib/context.js` — the Context Layer: date normalization, Local/Global interface scope, and `buildEmployeeContext(db, employeeId)`
- `scripts/context-demo.js` — prints the context object for one employee (`node scripts/context-demo.js VRD-1011`)
- `prompts/process-expert.md` — system prompt for the Process Expert agent (4-track model, learning↔doing pacing, mandatory/recommended/flexible taxonomy, "don't invent" rule)
- `lib/plan-validate.js` — validates a generated plan against the max-5-meetings/week rule **in code**, independent of the prompt
- `lib/process-expert-agent.js` — real Anthropic API call (requires `ANTHROPIC_API_KEY`); not yet run against the live API in this repo
- `scripts/run-process-expert.js` — builds real context, calls the agent, validates, writes `output/<employee_id>.json`
- `scripts/validate-plan.js` — runs the validator against an existing plan file
- `output/*.manual-example.json` — two plans (VRD-1011 IC, VRD-1054 manager) generated by hand against the real context + real prompt while no API key was available, then validated with the real validator code. **Not** live API output — see the filename suffix.

## Setup

```bash
npm install
npm run import
```

Requires Node 22.5+ (uses the built-in `node:sqlite` module — no native build step, no Python needed).
